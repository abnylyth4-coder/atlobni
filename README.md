# Atlobni (أطلبني) - On-Demand Delivery & Services

Atlobni (أطلبني) is an on-demand food delivery, grocery, courier parcel, and local concierge service application featuring real-time order tracking and full bilingual support (Arabic & English).

## Key Features

- **Multi-Category Delivery**:
  - Restaurants & Gourmet Food (Shawarma, Burgers, Charcoal Grills, Traditional dishes)
  - Fresh Supermarket & Groceries (Produce, Dairy, Pantry)
  - Specialty Cafes & Desserts (Artisan coffee, Spanish latte, pastries)
  - Pharmacy & Health Care (Vitamins, first-aid, skincare)
- **Wasselli Express ("وصلني")**: Door-to-door urgent courier service for packages, documents, gifts, and keys.
- **Any Request ("أطلب أي شيء")**: Personal shopper concierge service where a captain buys and brings anything from any store.
- **Live Order Tracking ("تتبع الطلب")**:
  - Animated step-by-step order lifecycle (Confirmed -> Preparing -> On the Way -> Delivered).
  - Dynamic simulation map with real-time captain scooter movement.
  - Interactive Captain info card, call simulator, and real-time in-app chat with driver.
- **Shake & Win ("هز واربح")**: Interactive lucky wheel spinner granting instant discount vouchers and promo codes.
- **Cart & Flexible Checkout**:
  - Item customization with sizes, sauces, and notes.
  - Multiple payment options: Cash on Delivery, Electronic Wallets, and Credit / Debit Cards.
  - Promo code discounts and order notes.
- **Bilingual & RTL/LTR**: Arabic (default RTL) with one-click English (LTR) toggle.

## Tech Stack

- **Framework**: React 18, Vite, TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Typography**: Cairo (Arabic) & Plus Jakarta Sans (English)
